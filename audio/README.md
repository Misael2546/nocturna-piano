# Muestras locales de piano

El motor de piano busca primero muestras MP3 en esta carpeta y luego intenta cargarlas desde la biblioteca Salamander alojada por Tone.js.

Nombres de archivo esperados:
- C2.mp3
- C3.mp3
- C4.mp3
- E4.mp3
- G4.mp3
- C5.mp3
- E5.mp3
- G5.mp3
- C6.mp3

Las muestras no se incluyen en este paquete. Para usar la app con audio acústico sin conexión, agregá archivos compatibles y verificá sus condiciones de licencia y atribución antes de redistribuirlos.
